# Style Guide (PaperMod-like)

## 1. Metadata

每篇文章必须有：

- `title`
- `summary`
- `author`
- `publishedAt` (ISO 8601)
- `tags` (2-6 个)
- `source.platform`
- `source.name`
- `source.url`

## 2. 标题规范

- 长度建议 16-32 字。
- 直接给观点或冲突点，不写空泛题目。
- 可使用 `：` 分隔“主题 + 结论”。

## 3. 摘要规范

- 1-2 句。
- 包含“核心问题 + 得到的结论”。
- 不重复标题原句。

## 4. 正文结构模板

```markdown
## 为什么值得收藏

(说明本文价值)

## 核心观点

### 观点 1
(证据与解释)

### 观点 2
(证据与解释)

## 可执行启发

- (行动项 1)
- (行动项 2)
```

## 5. 标签规则

- 至少一个来源标签：`微信公众号`、`X`、`博客`。
- 至少一个主题标签：如 `AI Agent`、`写作`、`产品`。
- 标签短语化，避免长句。

## 6. 来源透明

- 永远保留原始来源链接。
- 若来源不可公开访问，`source.url` 仍填原地址并在正文说明权限限制。
- 不删除作者名或出处。

## 7. 质量底线

- 不编造引用或统计数据。
- 不引入与原文无关的“热点嫁接”。
- 对不确定事实，明确写“待核实”。
